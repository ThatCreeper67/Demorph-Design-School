# Module 2 — Design Components

Version: 1.0.0  
Curriculum source: `design_curriculum.md` v1.0, Level 2 — Design component literacy.

## Learning goal

Classify the functional role an element appears to play, using the brief and surrounding visual evidence. Candidate roles include primary or secondary headline, supporting text, hero or supporting visual, information block, callout, brand element, decoration, caption, date/location, and call to action.

## Reasoning rules

- Visual form alone does not establish function. A large text object might be a title, quotation, product name, or decoration.
- Keep component type, semantic identity, and design role as separate fields.
- Assign one primary role; add secondary roles only when evidence supports them.
- Cite visible evidence and separately identify any role inferred from the brief.
- Mark uncertain roles rather than forcing a label.

## Assessment

Use macro-F1 for reviewed role labels, reviewer agreement for ambiguous cases, and evidence coverage for role claims. Do not count model predictions as reference labels.
