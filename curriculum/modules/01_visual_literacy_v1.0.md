# Module 1 — Visual Literacy

Version: 1.0.0  
Curriculum source: `design_curriculum.md` v1.0, Level 1 — Visual literacy.

## Learning goal

Describe what is visible before assigning meaning or purpose. Inventory text, people, objects, illustration, photography, logos, shapes, textures, decorative graphics, and background regions. Describe approximate location, scale, color, contrast, texture, lighting, and orientation when visually supported.

## Observation rules

- Record visible evidence separately from model inference and human interpretation.
- Transcribe only readable text. Mark uncertain text as uncertain; never complete it from context.
- Separate object identity (for example, a person) from design function (for example, hero subject).
- Use `unknown`, `ambiguous`, and `not_applicable` when evidence does not support a claim.
- Use normalized image coordinates for optional boxes: `[x_min, y_min, x_max, y_max]` in `[0,1]`.
- Do not infer a brand, identity, place, or authorship from resemblance or a filename.

## Practice and assessment

Create an image inventory without assigning design roles. Compare OCR text to verified transcription. Assess element classification, localization where annotated, and unsupported-claim rate. A static image supports apparent-attention hypotheses, not direct claims about actual viewer behavior.
