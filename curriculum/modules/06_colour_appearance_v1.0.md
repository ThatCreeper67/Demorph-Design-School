# Module 6 — Colour and Appearance

Version: 1.0.0  
Curriculum source: `design_curriculum.md` v1.0, Level 4 — Design principles and composition.

## Learning goal

Describe color relationships, harmony, contrast, saturation, temperature, lighting, texture, and atmosphere. Separate measured pixel properties from interpretation.

## Reasoning rules

- Color symbolism is culture-, audience-, and context-dependent; phrase it as a possible reading, not a universal fact.
- A sampled dominant color does not establish a palette's purpose or emotional effect.
- Note that display, compression, and image capture can affect appearance where relevant.
- Distinguish image evidence from brief-derived intention.

## Assessment

Use deterministic color measurements for pixel claims and human review for harmony or atmosphere. Report uncertainty and the method used.
