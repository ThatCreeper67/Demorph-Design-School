# Module 4 — Composition

Version: 1.0.0  
Curriculum source: `design_curriculum.md` v1.0, Level 4 — Design principles and composition.

## Learning goal

Describe relationships and organization: balance, alignment, proportion, grids, margins, spacing, negative space, symmetry/asymmetry, visual flow, focal points, grouping, overlap, layering, crop, framing, and edge interaction.

## Reasoning rules

- Identify the elements or regions involved in each relationship.
- Separate measurable geometry from qualitative interpretation.
- Intentional overlap is not automatically a collision or flaw.
- Do not force every principle onto each design; `not_applicable` is valid.
- Evaluate against the brief when one is available; otherwise state that purpose suitability is uncertain.

## Assessment

Use geometric checks only for claims they can measure. Use human review for qualitative balance, flow, and effectiveness. Link each principle to visible evidence.
